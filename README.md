# Full Stack Development Lab (FSDL)

## About the Repository
This repository contains my Full Stack Development Lab (FSDL) assignments completed as part of my B.Tech Computer Engineering coursework. It includes practical exercises and projects covering frontend development, JavaScript programming, React, and other full-stack web development concepts.

## Objectives
- Learn the fundamentals of web development.
- Design web pages using HTML and CSS.
- Add interactivity to web pages using JavaScript.
- Develop reusable user interface components using React.
- Understand how frontend and backend technologies work together.
- Practise Git and GitHub for version control and project management.

## Technologies Used
- **HTML5** – Structure and content of web pages.
- **CSS3** – Styling, layouts, and responsive design.
- **JavaScript** – Dynamic behaviour and interactivity.
- **React** – Component-based user interface development.
- **Node.js and Express.js** – Backend development, where applicable.
- **MongoDB** – Database operations, where applicable.
- **Git and GitHub** – Version control and repository management.
